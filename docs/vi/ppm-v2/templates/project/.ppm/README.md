# PPM 2.0
Thư mục này chứa metadata portable và báo cáo tự khai. Đọc contract trước khi dùng.
Thay proj-example đồng bộ; xóa update minh họa trước adoption và tạo initial update thật.
Dates/actor/checks trong template là ví dụ, không được nhập như lịch sử thật.
Mapping thiếu để null. UUID cho update/session mới. Baseline/acceptance chính thức ở PPM DB.
Registry host nằm ngoài repo. Session reporting theo hướng dẫn được owner cài trong AGENTS.md/CLAUDE.md.
